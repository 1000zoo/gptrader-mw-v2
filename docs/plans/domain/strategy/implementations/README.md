# Strategy Implementation Plans

This directory holds design notes and implementation plans for concrete strategy classes under `src/domain/strategy/implementations`.

Use one document per strategy. Each document should explain the market idea, required inputs, signal rules, edge cases, test plan, and implementation steps before code is added.

## Current Strategy Candidates

- `session-volume-profile.md`: intraday auction structure strategy based on session value area, point of control, and high-volume price acceptance.
